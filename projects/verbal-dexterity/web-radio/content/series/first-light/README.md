# First Light

A sample series for the first end-to-end milestone. These committed scripts are authored source text, not runtime-generated writing. The station name and editorial theme remain changeable.

- `programme.json`: two-speaker story, approximately five minutes depending on delivery. Measure the generated recording; the target is about five minutes.
- `ident.json`: short fallback station identification using the same two presenters.
- Voice recipes use prebuilt Gemini voices. No custom voice or reference recording exists yet. Each take retains the complete recipe and request; keep an accepted recording as the voice reference when available.

Edit the programme and ident independently in the studio. Saving edits creates private working scripts under `.runtime/studio/scripts/`; the committed examples remain available.
