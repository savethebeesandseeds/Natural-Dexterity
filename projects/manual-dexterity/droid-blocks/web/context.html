This is a supervised test on two known bodies. A and B are labels supplied by the experiment. Distinguishable readings would not, by themselves, show that a creature recognizes a returning place or retrieves a memory.

Look at the evidence behind these readings +

Eight complete action sequences (101–108) supply training examples. Four other complete sequences (109–112) are withheld for testing. Each sequence is run under both light conditions with matched actions. Neighboring windows from a test sequence stay out of training.

History uses one second of local sensor readings. The current-senses, brightness-only and without-light controls ask which readings carry information about the condition. A and B are evaluator labels; they are not extra inputs available to the creature. The plotted p(A) values are smoothed neighbor votes, not calibrated probabilities of correctness.

Accuracy is reported per withheld sequence and averaged equally across the four sequences for each body. The range describes those four sequence results. Overlapping sensor windows are not independent replications, and this page makes no window-level significance claim.

This static page reads a validated report from 48 native trials and 48 exact replays. It does not run or modify a creature. Results apply to these known bodies, action sequences and two light conditions.
