    A shared control-theory vocabulary

    What this model represents

    01 · Plant state x

    The physical system is nonlinear.

    The two-link mechanism has powered and passive joint angles and velocities. Motor current, temperature, safety state and delayed sensor queues add internal dynamics. The light source affects observations. One motor drives two mechanical coordinates.

    xk+1 = Fσ(xk, uk),   yk = hσ(xk, light)

    Body parameters σ change the plant. The predictor is fitted separately for each tested body.

    02 · Predictive state z

    A delay state we can actually measure.

    At each 0.1-second frame, y has 12 normalized local outputs: executed effort, encoder sine/cosine, motor speed/current, IMU force/angular rate, and light. The history model stacks 11 frames, latest first, followed by ten previous requests. Its state has 142 coordinates; the current-input model has 12, and history without explicit requests has 132.

    zk = [yk, …, yk−10, rk−1, …, rk−10]T

    This is an identified affine autoregressive model with an external input (ARX). It is not an observer of hidden joint state, and the fitted A is not a Jacobian of the physical equations.

    03 · Recursive prediction

    Predictions become the next state.

    Initialize z from measurements available at the forecast origin. Apply the known future request tape. Shift each predicted output into z, then predict again. Measurements after the origin are used only to score the forecast.

    The no-input comparison removes explicit past and future requests jointly; past executed effort remains in its output history. Persistence tests whether copying the latest observation already predicts well. Entire withheld trials test whether fitting has generalized beyond its training trajectories.

    04 · Control law π

    The RL controller remains the baseline.

    The live learner uses 56 hand-designed features and three linear action-value functions: Q(z,a) = waTz. Expected SARSA updates their weights, and an exploratory policy chooses one of three motor requests.

    Its 56-feature representation is separate from this predictor’s delay state. The new matrices do not yet choose commands. Prediction quality must justify any later model-based control experiment; it is not evidence of better control by itself.

    Where the transfer function fits +

    For this discrete-time affine surrogate, differences between two trajectories driven through the same fixed model satisfy Δzk+1 = A Δzk + B Δrk, Δyk = C Δzk + D Δrk. With zero initial difference, its requested-input/output transfer matrix is:

    G(ζ) = C (ζI − A)−1 B + D

    ζ is the discrete transform variable; z is the state vector. The affine c sets the baseline trajectory and cancels in these differences. This is the transfer matrix of the fitted surrogate at a 0.1-second sample interval. It does not establish a global transfer function for the nonlinear plant, controllability of its hidden physical state, or closed-loop stability.
